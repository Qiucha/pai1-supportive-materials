# Glossary

**Lab** — An interactive panel in a lesson where the learner changes inputs with controls and watches the results. A figure with no controls is not a lab, and neither is a check (a pick-then-reveal question). A merged lab combines several of a week's labs into one, with a case switch and one guide.

**Guide** — A short scripted walk through one lab that teaches 1–3 core ideas. It opens on its own the first time the lab is fully on screen, can be skipped or replayed, and ends in explore freely.

**Step** — One unit of a guide. It highlights the pieces it uses and dims the rest without locking anything, asks for one action on a real control, and ends with a notice. A step is done when the learner causes its target state while the step is showing; a state that was already true does not count. A step may start with a prediction.

**Prediction** — The learner's explicit choice about what will happen, made before acting. It is optional: if the learner made one, the notice shows it next to the actual result.

**Setup** — A condition the lab must meet before a step's action makes sense. The guide points at the control that meets it but never meets it for the learner. Not the same as the start state, which the guide sets when it starts or is replayed.

**Notice** — The line that replaces a step's instruction once the step is done. It says what changed and where to look.

**Explore freely** — The state of a lab after its guide is finished or skipped. No step is active and nothing is highlighted or dimmed. One open question is shown, which has no answer and is not checked.

**Bridge** — The connection between two separate labs in the same week: a "Next lab" link that appears only in explore freely, and a first step in the next guide that builds on what the previous lab showed, or names the contrast with it. Guides never chain automatically.
