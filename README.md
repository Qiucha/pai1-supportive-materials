# Probability for AI: self-guided learning pages

A set of self-guided learning pages for Probability for AI: a lesson hub (`index.html`) plus six weekly lessons in `lessons/` (Week 1 Chance, Week 2 Models, Week 3 Fitting, Week 4 Single neuron, Week 5 Neural network, Week 6 Breaking and auditing). Shared styles and scripts are in `shared/`, and third-party libraries (KaTeX, three.js) are bundled in `vendor/`.

To use it, open `index.html` in a browser. The pages work offline, with no server or install needed.
