Week 5 · Neural network. In Week 4, one neuron combined inputs into a probability. This week, four hidden neurons feed an output neuron. We keep the network fixed and change its input.

Can a few pixels change the answer?

Can you add a few pixels to a handwritten 3 so it still looks like a 3 to you, but the model says it isn't?

Make a prediction before you edit.

An adversarial example is an input someone changes to make a model disagree with a person's judgment. A changed model label alone does not prove that the edited digit still looks like a 3. You judge that part.

A network of neurons

This multilayer perceptron has 784 pixel inputs, four hidden neurons, and one output neuron. Each neuron multiplies its inputs by its weights, adds a bias, then applies the sigmoid function. The sigmoid maps the sum to a value between zero and one.

In Week 4 you rated the features by hand; here the network learned its own.

All four hidden neurons receive the same pixels. Their activations describe internal responses, not calibrated class probabilities. The output neuron receives those activations and multiplies them by its own weights. A higher hidden activation can lower the final probability when its output weight is negative.

The math

Trace the forward pass and the gradient

Write the image as $x$. Each pixel $x_j$ is zero or one. Hidden neuron $i$ has input weights $w_{ij}$ and bias $b_i$. Its activation is $h_i$. The output has weights $v_i$ and bias $b_{\text{out}}$.

$$h_i(x)=\sigma\left(b_i+\sum_{j=1}^{784}w_{ij}x_j\right),\quad i=1,\dots,4$$
$$p=P(\text{is 3}\mid x)=\sigma\left(b_{\text{out}}+\sum_{i=1}^{4}v_i h_i(x)\right)$$

Here $\sigma(z)=1/(1+e^{-z})$. The model is fooled when $p < 0.5$. At exactly 0.5 it still says "yes".

The chain rule multiplies the output slope, the output weight, the hidden sigmoid slope, and the input weight. It sums the contributions through all four hidden neurons.

$$\begin{aligned}\frac{\partial p}{\partial x_j}&=p(1-p)\sum_{i=1}^{4}v_i h_i(1-h_i)w_{ij}\end{aligned}$$
$$\begin{aligned}\frac{\partial\log p}{\partial x_j}&=\frac{1}{p}\frac{\partial p}{\partial x_j}\\&=(1-p)\sum_{i=1}^{4}v_i h_i(1-h_i)w_{ij}\end{aligned}$$

At a fixed image, $1/p$ is the same positive factor for every pixel. The probability slope and log-probability slope therefore have identical signs and rankings. The gradient strategy uses the log-probability slope.

A derivative describes a small brightness change at the starting image. A full binary flip changes zero to one. The linear approximation can miss that flip's effect because the sigmoid slopes change as the image changes.

Predict, then reveal

Check 1: Only one hidden activation rises. Its output weight is negative. What happens to p?

The negative output weight turns the activation increase into a smaller output sum. The sigmoid increases with its input, so p falls.

Going deeper

Change what you optimize

Training changes weights and biases to improve predictions on labeled examples. Attacking keeps those parameters fixed and changes the input to lower the probability of a 3.

Adding ink increases a pixel value, so we choose a dark pixel with a negative derivative. Removing ink decreases a pixel value, so we choose a lit pixel with a positive derivative. Both rules use a local approximation.

Brightness can take any value between zero and one. A partial brightness adjustment differs from a complete binary flip. Would trying every pixel and chasing a neuron still work? Trying every pixel still works, but you must choose a brightness step size for the comparison. Chasing a neuron still works because its signed weights give the direction to push its activation. Keep each adjusted brightness within zero and one.
