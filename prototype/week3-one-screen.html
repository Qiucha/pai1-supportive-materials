Where we are

Week 3 · Fitting. We used probability models to describe observations. Now we fit a model's parameters to observations.

Can you locate a phone using only how many packets it received from each tower?

Compare candidate locations by how likely they make the observed counts. Then use a gradient to improve a candidate.

A position and a score

The candidate parameter pair is $(x,y)$. Each position has a score. In a height plot, height represents that score.

The gradient points toward the steepest local increase. Its magnitude measures local steepness. Your move distance is a separate choice. A long move can pass a peak and land lower.

A small gradient is a stopping cue. A zero gradient at an interior point can occur at a peak, a valley, or a saddle. It does not certify the highest score.

The math

Score one tower

The model uses distance including tower height. The midpoint distance is 32 and the scale is 4.5.

$$d_i=\sqrt{(x-x_i)^2+(y-y_i)^2+8^2}$$
$$p_i=\frac{1}{1+e^{(d_i-32)/4.5}}$$

Here $p_i$ is a packet's receipt probability. With $n=50$ independent packet trials and $k_i$ receipts, the count likelihood is

$$\begin{aligned}L_i(x,y)&=P(K_i=k_i\mid x,y)\\&=\binom{50}{k_i}p_i^{k_i}(1-p_i)^{50-k_i}.\end{aligned}$$

The binomial coefficient stays fixed for each observed count. We omit it when comparing locations. The displayed contribution is $k_i\log p_i+(50-k_i)\log(1-p_i)$, a log-likelihood rather than a probability.

Combine towers

We assume the tower counts are conditionally independent given the candidate location. Their likelihoods multiply. Their log-likelihoods add.

$$P(\text{packets}\mid x,y)=\prod_i L_i(x,y)$$
$$\ell(x,y)=\sum_i\log L_i(x,y)$$

Taking the logarithm preserves the maximizing location. This scores observed counts given a location. It does not give a posterior probability of the location.

Take one uphill step

The parameter pair is $\boldsymbol\theta=(x,y)$. The step size $\alpha$ multiplies the gradient of the combined log-likelihood.

$$\boldsymbol\theta_{\mathrm{next}}=\boldsymbol\theta+\alpha\nabla\ell(\boldsymbol\theta)$$

The gradient only describes local change. A finite step can lower the score.

What region fits one tower?

One tower gives a ring of equal count likelihood. Three towers narrow the high-score region near the rings' overlap. Their rings need not meet at one point. The count likelihood is $P(\text{observed packets}\mid x,y)$. It is not a posterior.

Going deeper

Where the gradient comes from

At the current phone candidate, the horizontal arrow shows the x partial derivative. The vertical arrow shows the y partial derivative. A negative partial derivative points along the negative axis.

$$\frac{\partial\ell_i}{\partial p_i}=\frac{k_i-50p_i}{p_i(1-p_i)}$$
$$\frac{\partial p_i}{\partial d_i}=-\frac{p_i(1-p_i)}{4.5}$$
$$\nabla d_i=\frac{(x-x_i,y-y_i)}{d_i}$$
$$\nabla\ell_i=\frac{50p_i-k_i}{4.5d_i}(x-x_i,y-y_i)$$
$$\nabla\ell=\sum_i\nabla\ell_i$$

The chain rule multiplies the count slope, receipt slope, and distance slope. Each enabled tower contributes to both components.

What a small gradient tells you

All three terrains have height 0 and gradient $(0,0)$ at the center. Check the nearby heights at axis distance 1.

A zero gradient alone does not establish a peak. Even a local peak need not have the highest height elsewhere.

Why the fitted location can miss the phone

Both synthetic datasets use the same simulated phone at $(4,2)$. One rounds expected counts. The other draws 50 independent packet trials per tower with seed 2026. The generator uses $s_{j+1}=(1664525s_j+1013904223)\bmod 2^{32}$ and $u_j=s_j/2^{32}$. A trial receives a packet when $u_j<p_i$.

Both fits start at $(-12,0)$ with step size 0.5. Each stops when the gradient magnitude falls below 0.001 or after 300 steps. Packet noise can make the rings disagree. The combined fit compromises between their scores. Even rounded expected counts need not recover the phone exactly.

These results depend on the reception model and conditional independence given location. A different model can change the fit.
